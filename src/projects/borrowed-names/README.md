# 借名之城

一部原创中文城市奇幻侦探、潜入与社会角色扮演游戏。雾津用名字担保债务，衣服带有临时法律权利，一条街会随居民身份注销而物理关闭。这里没有引用既有小说、动画的人物或情节；所有场景、肖像、物件、台词与任务均为本项目创作。

## 内容与完整流程

三幕分别为「衣服里的人」「街道作抵」「黎明签字」。八处可到访场景：无字渡口、折伞巷、百面戏楼、量名署、留灯诊所、潮泵房、雨钟塔、借名公庭。六位反复登场的角色拥有不同肖像、身世、欲望、弱点、阵营与关系底线；十二项主支线委托提供一次性成长和经济报酬。

选择听雨人、戏面师或巡夜客，在名夹学习初始技能。先与阮灯交涉，核验收据；从折伞巷前往百面戏楼，取得袖纹。结算两项主线后进入第二幕。购买服饰走正门，或经屋脊潜入量名署；取得街产账、诊所脉波与泵房潮钟。保护或公开病人名单后，前往雨钟塔核验原令。六证互校，提交正确案由、实际印模及封街时序；领取案卷报酬后进入公庭，进行真实终审交涉，最后签署满足条件的契约。

正常流程约六十至一百二十次行动，夜晚最多容纳二百四十次。免费查看、阅读、选择勘验方法、操作地图与面板不计行动，不调用模型。核心回放上限仍为六百条。

## 三种代价

| 契约 | 必须亲自达成的条件 |
| --- | --- |
| 共名街 | 保护化名；送药并结算委托；互助会声望至少二；裴绡、乔砚或陆芦担保 |
| 有名之约 | 公开名单；未抵押本名且无救济债；署方声望至少二；贺迟或晏珩担保 |
| 借我作桥 | 保护化名；已抵押自己的本名，将债务永久转作道路担保 |

三者均须六件真实来源的物证、完整案卷与一次实际终审交涉。公开名单前，必须先安排署方担保并保有合格本名，避免把病人交给一个无法完成的承诺。精力耗尽、压力十二、警戒十或夜尽均会失败；可以保留记录，重新选择职业和路线。

## 规则与角色模型的边界

`engine.ts` 是纯权威规则，使用共享 `GameSession`、背包交易与阅历成长。所有玩家、角色和导入命令先严格解析再验证。种子决定印模、物件压痕与固定六面检定；模型不能改变真假、伤害、阅历、成本结算或胜利。初勘与潜入不能换姿势反复掷骰；任务、技能、工具与身份物品没有重复领取循环。

角色的工具只能提交交涉编号、有限意图、自知线索、零至四银的条件报价与短中文公开台词。每人仅能提供自己保管物证的位置，并根据欲望、信任、阵营、化名决定与公开记忆选择作证、扣留、议价、担保或巡逻。担保是独立的真实交涉，不是达到好感数字后自动发放。巡逻会改变后续潜入难度；公开名单会撤销相应民间担保。

只有按钮触发的实际交涉才调用共享原生客户端。每轮最多两次请求，每次最多一千五百三十六生成词元，整轮六十秒。网络错误、非法意图、过期回复与取消都不收取游戏资源；服务商仍可能收取已处理请求的费用。游戏没有离线角色替代，也没有生产环境夹具。配置、密钥与模型调用由共享控制台负责，本项目不另造客户端。

已成功提交的角色拒绝后，五银调档加两压力并降低阵营声望，换来物证位置而非证据。失败初勘可花四银复勘，失败潜入可花三银遮灯。终审拒绝后，可花六银行使一次强制陈述权。即使所有角色都拒绝，保护化名、抵押本名的作桥路线仍可达成，但必须完成六处真实交涉及终审交涉，并承担调档、休整等费用；不会变成免费离线谜题。

## 操作与可访问性

主画面与现场操作始终处于同一工作台；长剧情、人物、证据、背包与任务位于有界原生对话框。场景物件可触摸，也都有普通按钮替代。制表键切换，回车或空格操作；地图 `M`，名夹 `I`，委托 `J`，证据 `E`，须知 `H`。输入时和任意模态框打开时禁用这些快捷键。退出键关闭对话框。共享中文控制台的错误在手机底部保留独立可滚动区域。

所有重要操作文字至少十六像素，次级说明十四像素。采用中文系统字体，不请求字体服务。雨线遵循减少动态偏好，没有音频自动播放。项目使用作用域样式、生命周期绑定监听器，销毁时移除对话框与订阅。画面没有第三方素材或外部图像请求。

## 文件与扩展

`data.ts` 存放稳定标识、能力、经济、关系门槛、道路与委托定义；`story.ts` 存放原创实质剧情、角色传记、场景、任务段落和结局。`art.ts` 通过原创矢量路径绘制分层城市、实体道具、雨水反光与六幅版画肖像。`render.ts` 只呈现状态并请求命令；`index.ts` 连接项目页面、控制台与共享存档。存档记录种子和合法命令，不信任状态快照，不导出连接设置或密钥。

`agent.ts` 不依赖界面或样式。导出的 `smokeCase()` 返回 `{ request, verify }`，使用真实开场阮灯的有限行动，验证器会运行同一个规则归约器。可以由发布流程使用自己的合规模型执行；本项目不自动发起真实模型试用。

增加角色时，应同时定义其有限知识、实体物证、阵营底线、可达位置和担保限制；增加物品时必须扩展稳定物品枚举及容量约束；修改奖励、命令或剧情前置时应考虑已有回放的兼容性。不要把模型输出直接写成世界状态，也不要让新支线产生无限资源。

专属现有测试位于 `tests/rpg-games/borrowed-names.spec.ts`，通过测试辅助器拦截原生客户端，覆盖完整界面通关、替代结局、失败重开、中文手机与键盘、取消及导入，以及纯规则的证据来源、固定检定、经济、一次性奖励、全拒绝恢复与回放边界。真实模型兼容性和站点发布由合集的共享发布流程负责。
