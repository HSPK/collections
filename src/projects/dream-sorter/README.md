# 梦境分拣局

原创中文桌面键鼠街机。玩家是夜班邮政员，把折纸梦邮送回白昼或黑夜。四班，每班六件；三次误分或超时停机。没有触屏布局、音频权限、自动模型请求或离线督导替代。

## 开班与规则

点击「请督导开班」，通过共享连接设置接入支持工具调用的 OpenAI 兼容模型。有效派件返回后，先显示规则、编组与首件提示；点击「准备好了，开带」才走时。网络等待不会消耗机会。← / A 与 → / D 分别送白昼、黑夜；两侧邮槽与旁边的大按钮都可鼠标操作。首班首件有五秒与明确示范，之后不显示答案。

每班只有一条规则：太阳、橙色、**非月亮**、邮票**恰好两枚**或邮票**至少两枚**送白昼，其余黑夜。折纸形状只是辨识装饰。颜色有文字，邮票同时画数量与数字。正常窗口为 2.1–3.7 秒；难度仅开班前选择，不随班次无限加速。

每次正确签收得 100 分，加连签奖励（每连一件加 10，上限加 100）。误分与超时只扣一次机会，连签清零。四班完成按剩余机会颁金、银、铜印。整个流程只有两个暂存额度，每件最多暂存一次，延长截止时间 1.2 秒。重试与重新开班沿用种子、清空本次记录，不会自动请求模型。

## 真正影响玩法的模型

`agent.ts` 为纯模块，使用 schema/errors 的独立入口以及 client 的类型导入。`smokeCase()` 提供真实首班派件请求及引擎验证，由外部选择是否进行真实模型冒烟；游戏自身不会为测试调用真实 API。

督导根据公开错单（期望方向、玩家方向或超时）选择枚举规则、匀速/一紧一松/轻快节奏、三种方向编组及起始方向。首班只能选太阳或橙色，之后必须换规则，并改变编组或起始方向。各批固定六件、昼夜各三件、同向最多连续两件。所有包裹属性、唯一编号、到达间隔、截止时间和分类都由当地引擎生成和验证，不接收模型自定标签、分数或时间。

共享控制台提供中文连接、取消与公开行动日志；每次派件最多两次请求、每次 1536 输出 token、总限时 60 秒。失败保留原状态；无静默替代。派件前为完整轨迹预留 65536 字符，重开/导入会取消旧请求，提交还需 revision 检查。

## 固定时钟与可复核回放

`simulation.ts` 是唯一街机判定源。Phaser Scene 的 update 驱动 `FixedStepClock(50, 2)`，每步递增一个 tick；无第二个 RAF。每件在上一件完成后等待本地模板的 6–12 tick 间隔再到达，响应窗口精确为 **[arrival, deadline)**。输入作用于下一个 tick；截止 tick 本身算超时，不能抢最后一个已过期时刻。每 tick 最多一个方向或暂存输入。

`engine.ts` 的 GameSession 只接受难度、合法派件、整班 `{inputs, endTick}` 指令。输入最多 16 条，每班最多 4096 tick，严格递增且不能超出窗口；重复 ID、超额暂存、额外分数属性、结束后续走时、非终局保存都被拒绝。提交/恢复必须重跑同一个纯引擎，由轨迹复算得分、机会、连签和结局，不信任导入的状态或客户端得分。

共享 notebook 自动保存完整接受的班次与下一班派件。**正在玩的班次不保存半班输入；刷新或导入后从本班预告重新开始**，已完成班次完整保留。导出并恢复相同种子、批次和轨迹会得到相同结果。重新让模型规划可能产生不同编组，所以“同种子重新请求”不等于“同一回放”。这是本地可复核存档，不是联网排名或防作弊承诺。

手动暂停/P、所有原生对话框及文档不可见都会冻结时钟并清除待处理按键和时间余额。自动恢复不补离开期间的时间；手动暂停需手动恢复。长卡顿限制补帧，宁可减速也不跳过未见的操作窗口。

## 原创 Phaser 美术与资源

使用 Phaser 4.2.1 的 Scene、Graphics、Sprite、Container、Group、Zone 输入、Tween 与摄像机反馈。深靛邮政大厅、奶色折纸、橙/糖蓝邮槽、滚筒传送带、信封弹性入站、橡皮章与错误震动都是实际 Phaser 对象，不是整屏 SVG 或外置画布。一次绘制一个本地程序纹理图集并复用；三组信封显示池、十二片盖章纸屑池。减少动态效果时关闭装饰动画，判定与窗口不变。

逻辑画布 960×600，适配桌面 1280×720、1440×900 与 1920×1080。预算不超过 200 个显示对象、64 张本地纹理、32 个并发补间；实际计数显示在「班务」对话框。没有逐帧创建纹理，不声称所有机器都具有相同帧率。页面清理销毁 Phaser、订阅、监听器与待处理请求。

## 验证

`tests/phaser-games/dream-sorter.spec.ts` 使用现有 Playwright 与真实客户端协议 fixture，不含生产测试后门。覆盖所有规则的否定/等号/边界、批次公平性、严格轨迹、完整四班胜利、三次退件与重试、模型失败和取消、回放恢复、鼠标/键盘、暂停与资源稳定。浏览器测试通过 Playwright 时钟推进真实 Phaser 固定步，不注入胜利状态或代算运行时间。
