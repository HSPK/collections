# 余烬行旅

原创中文空岛帆车角色扮演游戏。九处可回访地点、三幕主线、十二项有前置与分支的记事、三名可招募同伴。六位具名角色各有肖像、身世、目标、缺点、关系及规则职责。没有借用现成作品的人物、对白或情节。

## 从一盏灯开始

在烬灯埠与岚缇商议，选择送灯的方式。通过悬缆峡后，静铃院、百帆集和逆花圃逐渐开放；逆风测绘将带你进入倒海池与空名库。借星台的议会揭示停风并非故障，而是被长期借用记忆的人撤回了许可。最终抵达无风炉心。

主线八项：第一缕不动的烟、桥上不是货物、没有声音的点名、逆着停风开花、倒影里的逃课者、天空吃掉的不是煤、不是每个人都想有风、最后一张地图的用途。

四项选做记事：一件披肩的利息，以及岚缇、墨鹭、巧砂的个人旅程。支线不仅添加故事，还改变战斗能力与结局资格。任务只奖励一次，不设刷怪或循环任务。

## 三种天空

- **长明航约**：击败最终守炉者，由领航员先承担记忆代价，开启救援航路。
- **无主的天空**：击败守炉者、完成墨鹭支线、留痕至少三点，拆除集中主环，接受更慢但不垄断记忆的航路。
- **共担的晨风**：完成三名同伴支线、解缆至少三点，在炉心提出轮值航约，不战解决。三项支线分别提供轮班、保留记忆与自由退出的执行办法。

车队生命归零会败北。失败不发任务奖励，不能靠扎营复活；可先导出这次旅途，再重新启程。

## 规则与操作

场景采用原创矢量立体浮岛、铜橙余烬和群青夜色；战斗使用三路九格透视地图。地图可点选站位，也可用原生选择框、方向键和按钮操作。对话框中滚动阅读，不依赖文档滚动。没有全局字母快捷键、音频、外部素材或动画触发的模型调用；尊重减少动态效果偏好。

每轮先请求公开的同伴与敌人战术，模型不知道玩家随后会选的动作。玩家再选择相邻战线、目标和技能。普攻不耗心火；烬火耗二心火并留下两轮灼伤；护持减伤并回复二心火；温灯药用一轮回复十六生命。敌人普攻重击预告一路，扫击覆盖落点与相邻路，躲开仍有二点擦伤。护持只保护所在路；敌人护持从本轮开始生效。先结算灼伤、玩家和同伴，再结算仍存活敌人。第六轮起悬缆每轮造成十二点额外损伤。

同伴共享车队生命，但各有独立三点心火和站位。岚缇擅长护持；墨鹭耗二心火疗愈；巧砂耗二心火破甲。护持回复一点同伴心火。三人的支线各增强其对应能力。商议的守诺、留痕、解缆提议分别提供首轮减伤、开战回复心火或首轮攻击祝福，不替玩家决定任务分支。

阅历曲线为零、二十四、六十、一百零八、一百六十八、二百四十。升级提高生命上限并给予航技点。烬火与守帆两种航技各有三阶。折光镜和帆织披肩共用单一装具槽；换装不会回血。城镇扎营花四铜叶；商店有持久有限库存，不出售回购套利，也不会自动补货。

## 代码边界与扩展

`data.ts` 定义标识、地点、物品、任务前置、分支成本与固定奖励；`story.ts` 承载分段原创叙事和人物资料。`engine.ts` 是无界面的纯规则，所有有效指令经共享 `GameSession` 的严格解析、预演、提交和原子回放。经济与成长分别复用共享库存、阅历助手。

`agent.ts` 只导入纯协议、错误和客户端类型；导出 `planTool`、`observation`、`SYSTEM` 与 `smokeCase()`。烟雾入口使用真实开场商议，并在验证中实际推进招募、任务和库存奖励。每个角色的观察列出公开目标、知识范围、资源和完整合法战术目录；模型不得决定伤害、奖励、等级或结局。公开文字严格限长、限制中文并转义显示。

`art.ts` 绘制原创肖像、九种不同建筑与战场；`render.ts` 输出有界面板与故事对话框；`index.ts` 绑定有生命周期的事件、共享中文代理控制台与共享中文游戏手记；`style.css` 全部作用域限定在项目根节点。没有新增依赖，没有生产环境离线代理替身。

新增剧情应先增加固定标识和任务前置，再写纯规则与合法目录，最后连接界面。不要在模型计划中添加任意资源或结局字段。失败、取消和过期模型计划必须保持资源、任务与战斗轮次不变。存档只保存种子与合法指令，不信任导入的状态对象。读取故事、选择目标和切换页面不进入回放。

普通入口为 `./projects/emberwake/`。需要用户主动配置支持工具调用的兼容模型，只有点击商议或战术才请求；每轮共享传输最多两次请求、每次一千五百三十六输出词元、总限时六十秒。连接与真实模型验收由集合层管理，项目不读取环境文件或自行调用真实服务。

针对本项目的现有运行器用例位于 `tests/rpg-games/emberwake.spec.ts`。测试专用原生工具响应经共享代理客户端进入游戏，不存在隐藏状态注入或生产替补。内容覆盖完整界面旅途、成长战利品、可选终局、败北、经济与战线约束、过期和失败计划、存档恢复与窄屏键盘操作。
