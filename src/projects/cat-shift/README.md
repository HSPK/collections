# 猫咪借位

一场五室、回合制的原创纸馆夜游。团团想在天亮前借走月牙沙丁鱼：先穿过前四室取得月牙签，最后取鱼并离馆。适用**桌面鼠标与键盘**，没有触屏控制层、实时倒计时或加载时的模型请求。

## 三条猫规矩

1. 点击相邻地板，或用方向键 / WASD 行走。每步之后巡夜员扫灯一次；红框、箭头和四步脚印提前预告。空格或点猫蹲一拍，也消耗一步。
2. 点「借位」或按 Shift 切换模式，再点相邻雕塑 / 纸猫，或用方向键交换。雕塑与纸猫挡住灯线；纸猫只挡一次。展品占着压板，出口才会开。模式按钮有明确选中状态。
3. 自动拾取月牙签 / 沙丁鱼，再走向箭头出口。警报四格或本室步数用尽即失败。每夜两次「重试本室」，保留已得星章，沿用**真实模型已接受的同一巡逻**；想重新选择整夜路线，用「新一夜」。

每室通关一星，零警报再一星，不超过本室巧步数再一星。每室只能结算一次；不能重试已完成的房间，不会重复刷星或跳关。完整胜利会显示五室总星章。暂停、重试、新一夜、玩法、手账始终在顶栏，模型设置和公开记录在底栏的中文原生对话框内。手账自动保存，刷新不触发模型调用。

## 五室渐进

| 展室 | 新窍门 | 步数 / 巧步 |
| --- | --- | --- |
| 打烊前厅 | 必须借位才能通过的折弯展道 | 20 / 10 |
| 大鼻子雕塑厅 | 雕塑遮挡整条灯线，绕开中央缺口 | 22 / 9 |
| 翘板藏品室 | 留展品压住开门板 | 24 / 11 |
| 真假猫画廊 | 一次性挡灯纸猫，十字形展室 | 26 / 13 |
| 黎明回廊 | 裂纹地板入格额外增加一格警报 | 28 / 13 |

移动先结算位置与遮挡，再扫灯、收走挡灯纸猫，最后检查警报、出口与步数。纸猫本次挡光有效，下一步才失去保护。最后一步恰好出门可以通关，但同一步警报到四会先失败。压板由展品持有，猫自己站上去不算。

## 巡夜员与可信边界

玩家在每室明确点击「请巡夜员落脚印」后，原生 OpenAI-compatible 客户端调用 `commit_night_patrol`。模型依据前室及重试公开路线选择：

- `lane: columns`：从北侧按列 `[2,4,3,4]` 往下扫灯；
- `lane: rows`：从东侧按行 `[1,3,2,3]` 往左扫灯；
- `offset: 0 | 1`：选择第一步节拍；
- `intention`：最多 80 字的公开意图，不请求或展示推理过程。

坐标从零开始，UI 列 / 行标记从一开始。共四种合法计划，选择真正改变灯光格、遮挡、警报与纸猫消耗，不是装饰性台词。每室一次显式调用，最多两次请求、每次 1536 completion tokens、整轮 60 秒；失败不模拟守卫。重置、导入、取消使旧请求失效；镜头 / 借位选择不改变世界版本。请求中行动被禁用，取消或失败不消费脚步、回头、星章或解锁。

`engine.ts` 的纯 reducer 决定位置、阶段、有限资源、单次星章和解锁。每个外部命令重新严格解析。`GameSession` 保存种子与命令而非可伪造分数，导入原子重放；存档证明规则合法性，不声称是模型调用的密码学凭证。全夜至多 120 个正常行动，加两次最坏 28 步重试、五次巡逻、四次换室及两次重试命令，**最多 187 条命令**；引擎另设 240 条上限。

## 可解性与画面

`solve(state, budget = 60000)` 对真实 reducer 进行有界广度优先搜索，状态键保留猫、展品、拾取和四拍灯光相位，以更少步数 / 警报支配剪枝。只返回真实合法移动、借位、等待的见证，不改门、不免伤。聚焦测试对每室四种守卫计划运行完整见证，并按同样动作实际通关 UI。没有随机掉落；纸纹由存档种子产生，新一夜顺序推进种子。

真实 `Phaser 4.2.1` 场景使用八张一次生成的原创纹理、Sprite、Graphics、Zone、场景 tween 和十二粒复用纸屑池。暖漆红 / 孔雀绿 / 象牙白纸馆、胖猫、夸张大鼻子雕塑、脚印与灯锥都在 Phaser 内绘制；无 SVG 冒充游戏、外部贴图或第二条动画循环。逻辑分辨率 960 × 640，适配器 FIT 缩放；纹理与对象在重试 / 重开时复用。预算 ≤200 对象、≤64 纹理、≤32 tween；玩法对话框显示实测值。默认无音频，不创建 AudioContext。减少动态效果时取消装饰 tween，暂停 / 隐藏文档 / 原生对话框由共用舞台管理。

- `agent.ts` 的 DOM / Phaser 无关 `smokeCase()`：生成真实开场巡逻请求，校验接受的计划，使用见证推进第一室并形成第二室公开路线历史。真实模型验证由发布流程另行显式执行。
- 只运行聚焦测试 `npm test -- tests/phaser-games/cat-shift.spec.ts`；网页地址使用相对的 `./projects/cat-shift/`。

资源基线为 104 个场景对象、19 张总纹理，空闲装饰最多一个补间；重开应维持相同数量。扩展展室或特效时，使用现有完整局程与重复重开用例确认仍在预算内。普通自动化使用原生客户端夹具；真实模型调用通过显式启用的串行验收入口运行。
