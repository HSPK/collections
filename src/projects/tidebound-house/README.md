# 潮汐归客

一座海屋在岸边借住七次潮水。五位旅客、一个临时主人与一座会改变主意的房子，共同修成留下、远行或往返的生活。本作人物、地理、旧约与情节均为原创，不改写任何既有小说的人物或剧情。

独立页面：`./projects/tidebound-house/`。项目标识 `tidebound-house`，序号 86，中文 Agent RPG。需要自行配置支持原生工具调用的 OpenAI 兼容模型；不会在载入、读档或动画中调用模型，没有离线假扮旅客的逻辑。

## 内容与三幕

`story.ts` 收录完整开篇、三幕正文、七潮提示、五篇人物传记、五次坦白、十种人物收束、三个结局和有限失败，含 4084 个汉字。`data.ts` 另有 1641 个汉字的地点故事、人物外形、机械门槛、物品与任务说明，两者合计 5725 个汉字。

| 内容 | 数量与作用 |
| --- | --- |
| 常驻旅客 | 五位：沈砚、林汐、何缝舟、余笺、陶芽；独立肖像、衣着轮廓、个人目标、缺点、关系门槛、有限行李和议程 |
| 可访问地点 | 十处：潮灯厅、补帆工房、雨信阁、屋心阁、拾光滩、贝壳港、回声岬、旧约石庭、悬雨花台、折光灯塔 |
| 任务 | 十二项：五项主线、五项人物约定、两项支线；各只结算一次 |
| 待客之道 | 三种：识潮客、匠心客、听故事的人；不同初始技艺、纪念物和真实能力 |
| 成长与行囊 | 五级、三项技艺、四点升级研习；十三种物品、一个纪念物槽、四种有限编号配方 |
| 结局 | 三个需兑现条件的胜利结局；第七潮期限失败与人心过低失败，可完整重新开始 |

第一幕修炉座、听见五个人的开篇，并把滩纹与借宿簿拼成潮图。第二幕揭开不替别人决定的旧约，修灯塔和屋心，亲手兑现彼此交错的人物约定。第三幕为海屋留下第六把椅子，用实际支持与物资落实新约。

沈砚与林汐分别知道熄灯那一夜的两端；何缝舟误认的债与余笺未寄的回信必须交叉听取；陶芽则要等灯塔证明“有得选择”，才愿意让花盆与房子搬家。不是无限生成的零散小故事。

## 规则

每潮分退潮、灯时，两段各七行动，共十四段。现实时间不推进世界。移动、拾取、修复、交易和成功的旅客议程各花一行动；技艺不足时，听开篇、辨读、制作改花二行动，而不封死道路。升级研习有限，查看、镜头、阅读与菜单免费。

识潮客从识潮二与无北针开始。匠心客从匠艺二与船形针开始，榫骨少用一份潮木。听故事的人从共情二与听风缎开始，远程递信免贝钱。装备只加一项技艺一，不叠加；换装花一行动。二级技艺决定节约行动的门槛。

海岸五处材料存量与港口现货都有限，不随潮段刷新。使用共用 `createInventory` / `exchangeInventory`，容量八十、单种上限二十四，先确认全部支出再结算收入。没有卖回、拆解、重复领取或材料净额造物。配方最多为透镜二、榫骨一、归潮结二、盐花茶五；同配方只有首次获得经验，每人只收一次茶。成长使用共用 `gainExperience` / `progression`。

立约需要开篇与二点羁绊，带走或放下只能选一次。兑现还需要对应证据、相关旅客的开篇和真实材料。通常在两潮后到期；错过扣一人心、一羁绊，只可用额外行动与贝钱重订一次。人物任务只奖励一次；已兑现且羁绊三以上才提供仪式支持。人心降至一，海屋提前归潮。

错过会面时可在访客册递信：比当面多一行动、一贝钱，代价在按钮上明确列出。信可以完成同样的人物动作，但不伪造 Agent 行动。有限港口换物、花台贝钱和旅客援助提供资源备选。第七潮最后推进之前有明确警告。

## 旅客议程与信任边界

`agent.ts` 不依赖界面入口或样式，单独导入共用 schema、错误类型与请求类型。五位旅客分别拥有自己的有限已知线索，只有同桌交谈才彼此共享；模型接收目标、缺点、关系搭档、公开记忆、主人本次邀请方向和每人的小型合法目录。

每人选择一次长桌相遇、交出行李援助、沿岸发起会面或休息。接受后人物确实移动到地图中的对应地点。至少两人同桌才能交换知识；搭档相遇产生人物连结。相遇与外出共享每人每潮一次羁绊上限；援助真的减少该人物的两份私人储量。旅客交换的信息不会冒充主人亲手辨读的证据。

模型只提交当前潮段、五个有界目录选择与简短中文公开意向。严格拒绝多余字段、重复人物、过期潮段、非法目录、全体歇息、非中文意向、网址与代码围栏。模型不能发经验、物资、完成任务、修改承诺或宣告结局。所有模型文字均以文本或转义标记呈现。

共用控制台每回合最多两次请求，每次最多 1536 输出令牌，整回合 60 秒。`preview` 先校验，提交前再核对单调修订号，同步 `dispatch` 才改变世界。错误、取消与过期不消耗行动。重置和导入取消旧请求，镜头与地点查看不取消。没有后台循环或自动模型请求。

`smokeCase()` 提供真正开篇的 `{ request, verify }`：已经领取钥匙并修好炉座，由模型选择五人议程；验证函数通过实际 reducer 检查一次行动消耗、一次议程记录、真实移位，以及连结／关系／有限物资的机械变化。

## 完整旅程与结局

推荐先以匠心客入门：修炉座，邀请长桌，听五人开篇，升级共情；收拢称呼后辨读拾光滩与雨信阁、合读潮图，升级识潮。在工房做透镜、榫骨、两个归潮结与一份茶；双岸还要第二枚透镜。拾取潮木、海玻璃，修灯塔，辨读岬角与石庭、刻潮标，然后修屋心。

返回长桌后按证据兑现人物约定，避免过早立约后忘记期限。第五潮起，在三位旅客已兑现、至少三次真实议程及屋心已修的条件下议约。第七潮到屋心阁选择仪式。完整五人、十二任务、成长、交易、赠礼与制作的正常旅程低于三百个有效命令，保留共用六百回放上限的充足余量。

| 结局 | 除议约、屋心与灯塔之外的真实条件 |
| --- | --- |
| 岸上第八扇窗 | 支持三、留岸三；消耗月盐二、归潮结一、潮木二 |
| 把故乡带向远方 | 支持三、远航三；消耗月盐二、归潮结一、海玻璃二 |
| 两岸之间的一盏灯 | 五人支持、留岸二、远航二、两组旅客连结、潮标；消耗月盐二、归潮结一、返照透镜一 |

兑现“放下”提供留岸，兑现“带走”提供远航，潮标额外提供留岸一。双岸不是通关后的装饰文本，而是必须维持不同选择、实际人物连结与额外透镜的另一套仪式。

## 画面、操作与保存

主场景为手绘形状组成的 SVG 海岸与海屋剖面：雨幕、蓝绿海玻璃色、珊瑚屋顶、琥珀窗光、反射与独立家具。五位人物的发型、体形、衣物及随身物件可在房间里辨认，位置来自权威日程。修复会点亮炉座、灯塔与屋心。小屏可近观所选地点，另有免费全景按钮。

地点下拉与 SVG 房间均可用键盘和触控。选择地点只查看，前往才移动；“此地事务”提供当前地点的有效动作与缺失条件。访客、行囊、手记、指南与终章使用有界原生对话框，不靠文档滚动。持久根节点具有可见标题、中文语言与工作区标记。

空格邀请旅客，左右方向键切换查看地点，回车打开此地事务，问号打开指南。快捷键在原生模态框、按钮、输入和选择控件中停用。退出键关闭阅读页。尊重减少动态效果，完全无声；观察器和事件监听在卸载时清理。

共用中文模型控制台始终在底栏，错误全文可在模型设置或日志查看；右下角给集合菜单留白。共用中文游戏笔记本在每次合法命令后自动保存，导入用纯 reducer 原子重放，不信任状态快照。配置与密钥不会进入回放。
