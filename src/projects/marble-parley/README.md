# 弹珠外交

月亮的归属，不靠演讲，而靠一台老式太空弹珠机。五位原创外星使馆代表，把港口、花园与夜空化作三枚发光契约；第五轮由铜冠大使长主持。桌面鼠标与键盘游戏，不要求手机或触摸层。

## 十秒上手

1. 在「模型」中连接兼容 OpenAI function tools 的真实模型，点击「邀请使馆布阵」。
2. 铜盾与弹台全部亮相后，拖住底部弹珠向后拉，松手发射；也可使用角度/力度滑条。
3. 每轮三枚弹珠，签署任意两份契约过关；终章必须签齐三份。五轮全过即获胜，任何一轮三球耗尽未达标即失败。

← → 每次调整一度，↑ ↓ 调整五点力度，空格发射，E 装填/卸下本轮唯一的连签电荷，P 暂停，? 查看玩法。输入框、滑条及任何原生弹窗保护快捷键。鼠标离开画布、取消捕获或切走窗口会清理未完成的拉球。无音频上下文、无音效、无离线假对手。

**连签电荷**在发射时消耗。球先撞铜轨或弹台，再命中光印，才能自动连签最近的另一份契约；一球至多触发一次。光印可穿过，铜盾与弹台才产生反弹。先观察盾的正面遮挡，再尝试侧击、擦碰与连续折返。

## 本地规则与真实对手

- `data.ts`：五种不同形状的原始板面、三种弹台阵型、三处可选盾位、三种种子目标偏移，共 135 种有限几何。
- `physics.ts`：唯一权威的纯二维圆/线段引擎。120 Hz 固定步长，每步两次微步，每微步两次碰撞松弛；最大速度 940 px/s，最大微步 3.92 px，小于球半径 8 px。圆端点参与碰撞，位置与速度量化到六位小数。每球最长 600 步/5 秒，最多记录 96 次接触。
- 普通轨道恢复系数 0.94，弹台 1.04，重力 105 px/s²。每步限速；底部漏球或寿命耗尽即结束。目标每球只计一次，分数、连击、星级、剩余弹珠及结束条件完全本地计算。
- 第 1 / 2 / 3 个不同契约分别得 100 / 200 / 300 分；每种已撞过的反弹面给每份追加 20 分。每枚弹台首次接触另得 25 分；过关每枚剩余弹珠加 150 分。星级为剩余弹珠 + 1，每轮最多三星。
- `solve` 用相同模拟器检索有限合法角度/力度，并验证至多三枚普通球的目标并集。**接受任何模型板面前必须通过求解**，不要求特殊电荷。求解器不是画外自动玩家，不修改得分。
- `agent.ts` 只允许 `formation`、`defend`、中文短句 `intent`。模型依据公开的历史角度、力度、契约与反弹统计，真正选择弹台位置/大小与护盾目标。布阵只在回合间发生，发射后不能插入反击。第一轮无统计，模型自主选阵。
- 复用共享中文 Agent Console：revision/preview/commit、防旧请求覆盖、回放容量预检；一轮最多两次请求，每次最多 1,536 completion tokens，60 秒截止。验证失败和网络失败不扣弹珠，不改变已接受的板面，不调用离线替身。API 费用仍由服务提供方决定。

## 回放、暂停与资源

`GameSession` 只记录种子与经过严格校验的布阵/角度/力度/电荷指令，不接受外部声称的分数、轨迹或世界状态。一次发射仅一条命令；五轮完整战役最多 24 条（远低于共享 600 条预算）。Notebook 自动保存，支持导入/导出；导入先在草稿中完整重算。

**发射当刻就提交扣球及整个权威结算**；Phaser 逐步播放同一份引擎轨迹，不用第二套 Arcade/Matter 物理。刷新、关闭页面或切换存档不会让已发射球免费重来。页面恢复显示已保存结算，不继续调用模型。显式重试/新星图才重置战役；打开重开弹窗本身不改进度。

`scene.ts` 使用真实 Phaser 4.2.1 Scene、Graphics、Sprite、Image、Container、交互 Zone、Input 与 Tween。铜轨、五位肖像与五种板面为原创程序图形；一个自制纹理图集只在建场时生成。球尾池固定 18 个，粒子池固定 20 个，弹台/目标对象复用。共享 `FixedStepClock` 驱动轨迹消费；掉帧仅放慢、不跳过物理帧。原生弹窗、后台页面及显式暂停都冻结场景、清除时钟余量。

预算为 **≤200 显示对象、≤64 纹理、≤32 并发补间**。「玩法 → 测量画面资源」读取真实 stage metrics。桌面 Playwright 完整五轮样本实测 **70 对象、18 纹理、1 个空闲装饰补间，14 条战役命令**；重复三次三球败局和重开后，对象/纹理数量不增长。碰撞时短暂增加弹台补间，固定池不扩张。减少动态效果模式移除粒子、拖尾与装饰运动，不改变球路。销毁清理监听器、Phaser 实例与页面资源。

目标桌面尺寸：1280×720、1440×900、1920×1080，无文档滚动；画布保持固定逻辑分辨率并 FIT 缩放。控制文字最小 14px。软件 WebGL、重负载设备可能放慢轨迹显示，不能保证所有设备恒定帧率。

## 验证入口

现有 Playwright 测试：`tests/phaser-games/marble-parley.spec.ts`。覆盖 135 板面可解性、角落/薄轨高速碰撞、目标只计一次、连签、确定性与逐步一致、纯模块、严格导入、真实 UI 五轮胜利、三球败局/重试、新种子、鼠标拉球/键盘、暂停与弹窗、模型失效/取消、防旧提交、存档与重复运行资源预算。

纯 `agent.ts` 导出 `smokeCase()`，包含实际 `AgentRequest` 和执行真实 reducer 的 `verify`，供单独授权的串行真实模型检查。日常端到端测试只在测试侧拦截原生工具响应，生产代码不包含夹具。
