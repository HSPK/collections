# 森语契约

一款原创中文缔灵冒险。祈芽岭的季节会迁徙，玩家简禾从永春的村庄出发，学习修复人与灵之间破损的约定。水彩纸纹、剪纸植被、分层季候地景与原创角色均由本项目的矢量图形绘制，无外部图片素材。

## 内容与旅程

三幕故事，八处独立地景，七位有形貌、传记、愿望、缺点和牵系的主要人物，三位可结契、训练、蜕变的元素伙伴。七项主线仪式与六项人物支线构成十三项约定。完整正文集中于 `story.ts`，包括地点叙事、人物、任务前后文、三种结局与断契失败。

主线顺序：倾耳苔林、倒铃浅川、白契石庭、悬叶驿、眠灰窑、雪根眠湾、行季冠顶。苔林后回村承认或暂存旧账；石庭后决定拆锁或留桥；冬湾后决定让出暖季或随灵迁徙。途中可回访旧地。轮守需要承认旧债、兑现人类支线并让伙伴成长；迁徙需要真正的同行羁绊；作桥需要成长与亲手制作的符饰，代价是放弃远行。冠顶仪式不会自动替玩家选择结局。

## 操作与空间规则

地图旅行，行囊制作与佩戴符饰、结契与成长，约簿履行支线及作出承诺。长篇内容放在原生弹窗中，世界与主操作留在同一视口。

阵地为五行五列。选择木、火、水，再点击相邻阵格：木起、水收，含火，火水之间须有木，不能穿墙或重复，共五至十一格。地面浅色石纹提供可行路径，但不会自动填写。湿地用水、荆棘用木可省息。选择伙伴后点击阵格安排真实站位；接引需要靠近对应元素，护持用于承担裂隙。蜕变扩大作用距离，个体羁绊解锁专属能力与树冠道路。

数字一、二、三选择元素，方向键移动阵格焦点，回车或空格选格，退格撤字。所有键盘动作均有触摸按钮，弹窗和文字输入会屏蔽快捷键。系统减少动态偏好实时生效，声音默认关闭，只有主动开启后才发声。

“落笔布阵”提交本地布局，“请灵应答”才请求模型。模型扮演有独立目标与记忆的野灵、伙伴，从严格合法目录中选择公开意图。野灵可以靠近、试探或筑障；伙伴可以接引、护持、观望，满足条件时也可抗拒。拒绝会真实改变裂隙或共鸣，不是装饰性对白。

## 权威边界

`engine.ts` 是纯函数规则引擎。所有玩家、代理、回放命令都经过严格对象解析，检查阶段、标识、几何、元素语法、费用、装备与成长。模型不能授予资源、经验、胜利，不能编辑阵式或执行任意内容。非法、取消、过期的应答不耗息、不发奖励。断契先于共鸣胜利判断。

使用共享 `GameSession` 管理预演、提交、修订、订阅、重置与原生验证回放；使用共享库存交换验证先付费后收益及容量，使用共享成长曲线发放升级点。采集每处一次，制作每式一次，训练、蜕变、任务奖励分别一次。背包七十二格，单类上限二十四。每次应答基础一息、地形额外至多四息；燃愿可选两露供奉。撤阵后可休息恢复十二息，不补发物资。基础训练仅需落枝与息力，避免露珠用完堵住主线路口。

每场需六至十二共鸣，七裂失败。正常完整旅程远少于六百条回放上限；选择、读取故事、移动焦点、声音设置不产生世界命令。布局的逐格编辑也是本地草稿，仅落笔时记录一条命令。

## 文件与扩展

`data.ts` 保存标识、地景、配方、成长、伙伴和任务条件；`story.ts` 保存原创正文与中文规则；`engine.ts` 管理所有权威结算；`agent.ts` 定义纯代理工具、公开观察与角色提示；`render.ts` 绘制矢量地景、形貌、阵地和阅读面板；`index.ts` 负责共享会话、中文代理控制台、回放手记与生命周期；`style.css` 处理独立全屏布局与响应式绘画。

扩展地点时须同时更新地形、可行阵路、主线前置、叙事与场景形态。扩展伙伴时须同步严格工具目录、解析器、合法动作、站位距离与记忆观察，不能只增加一张人物卡。规则变动后旧回放须重新逐条验证；不兼容回放会被明确拒绝，不静默迁移资源。

## 模型与验证入口

运行时为共享的开放兼容模型连接，中文控制台与中文回放手记均传入 `zh-CN`。不在挂载时请求，不提供离线代理。每个明确回合至多两次请求、每次最多一千五百三十六个完成令牌、总时限六十秒。服务端兼容性、跨域和计费由用户的模型服务决定，密钥不会进入游戏回放。

纯 `agent.ts` 导出 `smokeCase()`，返回实际苔林开局的 `{ request, verify }`。它不依赖界面或样式；任何合法开局模型意图都会耗一息并产生不同的真实共鸣或裂隙，验证器不接受叙述性胜利。扩展模型适配时，可将该入口接入串行验证流程；入口本身仅构造请求和校验函数，不主动访问网络。

限定测试文件为 `tests/rpg-games/verdant-oath.spec.ts`，使用现有原生代理夹具覆盖完整界面旅程、三种结局、蜕变与成长、失败重启、取消和回放、空间与经济边界以及中文移动端操作。
