# 纸上守夜

原创中文桌面键鼠街机：三盏折灯保护一座纸城。墨影被照成纸屑与星星；没有普通射击、聊天框、RPG 菜单或触屏控制。五更各 24 秒，第四、五更是双折墨冠的上下阕。

## 三句话

1. `1 / 2 / 3` 选灯；点击舞台巷道会选灯并闪一下。
2. `空格` 闪光，金边才可照散；墨冠需两次，相隔至少 0.4 秒。
3. 别长按：闲灯回能散热。`P` 暂停，主栏随时可看玩法或重新守夜。

初始三道城折。漏影扣一折，归零结束。每更守成后选一次扩容（每灯 +20 能量）或风褶（每闲刻 +1 散热），随后请求下一更。得星、连锁、损失与奖灯均由本地规则确定。金灯要求五更无伤且空闪不超过五次，银灯要求通关余两折，其余通关得星灯。

## 真正的 Agent 边界

`agent.ts` 是可单独导入的纯模块。`conduct_ink_watch` 严格解析有限队形、焦点巷道、32/36 刻间距、墨蛾/纸鸢/换巷客、换巷开关及 70 字以内中文公开意图。模型选择会改变真实生成分布、时序、金边窗口与假动作，不是换一段旁白。观察只有上一更公开的用灯分布、命中、空闪、连锁、城折和改造。

模型不接收当前按键，不修改运行中的预告，不决定奖励，不返回代码或 URL。中文界面的共用 AgentConsole 执行最多两次请求、每次 1,536 completion tokens、整轮 60 秒期限；使用 revision 校验、preview 后原子 dispatch，以及 `assertCanDispatch(65536)` 预留回放空间。加载不发请求；失败、取消、迟到回复均不创建波次或扣资源。没有离线指挥替身。取得合法预告之后，必须由玩家点击「准备好了 · 开更」，再开始本地时钟。

`smokeCase()` 返回真实首更请求和校验器：校验模型的真实墨影在第 20 刻生成，且同一计划可经固定步引擎取得完整首更。实际模型冒烟由发布流程串行显式运行；项目与测试不会直接访问真实模型。

## 公平性与可解性

- 固定步长 50ms，每更 480 刻；第一个影子在 20 刻出现，后续间距只允许 32 或 36 刻。各更总数为 8 / 9 / 10 / 11 / 12；最多两个同时存活。最晚生成为 416，最晚触城为 476，均在结束前。
- 墨蛾/墨冠在出现后 24–60 刻可照；纸鸢/换巷客为 32–60 刻。换巷客若启用假动作，前 24 刻在右邻巷，箭头从出现即公开最终巷道；然后固定移至目标巷。不是按玩家输入反应的突袭。
- 每盏初始 100 能量；一次光消耗 28、增热 32、冷却 8 刻，热度大于 68 禁止发光；未发光的灯每刻回能 2、散热至少 2。不成功的按住尝试不会绕过冷却，但连续有效发光会耗能积热。换灯无移动成本。
- **统一构造解**：每只出现后第 36 刻照目标巷；墨冠第 44 刻补照。最紧间距 32 刻，即使所有影子集中一巷，双闪后到下一只至少有 24 刻。两闪分别在 36/44 刻发生，最坏双闪周期消耗 56、30 个闲刻恢复 60；热增加 64、30 个闲刻至少消去 60。实际墨冠在第四更每三只、第五更每两只出现，中间单层影子的空闲足以清热。无改造也能通关所有 540 个更次/编排组合。测试逐个运行完整构造解；没有只证明一套固定 AI 的捷径。
- 闪光先于当刻触城判定，故第 60 刻的有效闪光仍救得下。照散基础 100，连锁每级加 10（上限 200），出现后 44–52 刻照散加 20；空闪或漏影断连。第三折归零立即终结，之后无输入/计分。

## 权威模拟与回放

`data.ts` 存目录与固定表；`simulation.ts` 仅在其自有 Round 上逐刻改变生成、灯能/热、命中、连锁、逃逸；`engine.ts` 是 GameSession 的纯 create/reduce/parse 定义。Phaser Scene 的 update 使用共用 `FixedStepClock(50, 4)`；长帧每次最多四步，不跳过未见过的逻辑。没有自建 RAF 或物理循环。

每更最多 480 个 `{tick,lane,pulse}`，每刻至多一条；按住会记录逐刻意图，选灯和单击在下一逻辑刻合并。解析严格检查字段、整数、布尔值、顺序、数量和结束窗口；结束后输入、伪造分数、重复刻、半更终结均拒绝。仅完整更次的 trace 与 endTick 提交给 GameSession，由引擎从初态重新演算结果，不提交玩家声称的分数。

中文夜巡手记自动保存已接受编排及**已完成更次**。导入/刷新保留完成记录；未完成一更回到同一公开计划的准备页，按键、热度、时间从该更起点重开，不回退此前得分或城折。导入验证完整回放后才替换状态；取消所有旧请求。有效导入不自动请求模型。重开清除当前局，导出可保留旧局。

手动暂停、document hidden、所有原生模态弹窗均冻结 Scene 与逻辑，释放长按并清除时钟余量；恢复不追赶隐藏时间。失焦也释放按键。文本输入、弹窗、合集菜单不捕获快捷键。无 AudioContext、声音默认关闭（此作品不提供音频）。

## 舞台与资源

真正 Phaser 4.2.1 Scene / Graphics / Sprite / Container / Group / Tween / Pointer input：分层纸城、可折建筑、宣纸月、朱砂灯、光锥、手绘轮廓、换巷箭头和星屑池。不是 SVG 或自绘 Canvas 盖在空 Phaser 后面。纹理仅开场生成一次。

逻辑画布 1440×640，FIT 适配桌面 1280×720、1440×900、1920×1080，保留主标题、暂停/玩法/重开以及底右合集菜单净空。不做手机布局。仅固定 HUD 数值更新，无逐帧重建 DOM 控件。

确定上限：164 个显示对象（含容器子对象）、6 个本地绘制纹理（加 21 个 Phaser 文字纹理共测得 27，总预算 32）、16 个装饰补间，墨影 Sprite 池 12、箭头池 12、星屑池 36；没有逐更增殖对象。减少动态停止建筑/月光装饰与影子摇摆，保留必要移动与闪光反馈。项目监听使用页面 AbortSignal，stage 与 Phaser 资源由统一生命周期销毁。这里是资源预算，不是未测量的帧率承诺。

## 验证

已有 Playwright runner 的 `tests/phaser-games/paper-watch.spec.ts` 包含纯规则/死亡边界/540 编排可解性，以及拦截真实 native-tool 客户端的完整五更合法键鼠胜利、失城重开、暂停/弹窗/隐藏、中文设置键盘隔离、网络失败/非法回复/迟到取消、原生回放导入导出和资源预算检查。UI 测试仅加速浏览器时间，仍通过真实按键与 Phaser 指针进行游戏；不注入胜利状态或生产替身。
