# 中文 Agent RPG：开始冒险

这五款游戏使用原创角色与世界观。界面、剧情、任务和角色对白均为中文；
内部标识与模型名称仍可能是英文。游戏规则、画面、装备和结局在浏览器
本地计算，LLM 负责角色的选择与行动，不负责凭空修改数值或宣布胜利。

## 连接模型

在游戏中打开模型设置，填写支持原生函数工具的 OpenAI 兼容接口及模型。
仅打开页面、读剧情、整理界面或恢复存档不会请求模型。需要角色行动时，
由你主动发起请求；服务商可能按调用收费。

如果已经将远端 API 的 8080 端口转发到运行浏览器的电脑：

```bash
ssh -N -L 8080:127.0.0.1:8080 your-ssh-host
```

接口地址可填 `http://127.0.0.1:8080/v1`。接口必须给实际响应和预检响应
正确配置 CORS；SSH 本身不会补充 HTTP 响应头。`usm openai-proxy` 的
1.4.3 及之后版本包含这项修复，更新后还需重启旧进程。
浏览器若要求本地网络访问权限，只对你信任的网页允许该权限。

也可以在本地运行整个合集和同源网关：

```bash
npm run build
npm run games:serve
```

打开 `http://127.0.0.1:4174/`，模型接口使用
`http://127.0.0.1:4174/api/openai/v1`。此网关默认连接同一台机器上的
`http://127.0.0.1:8080/v1`，因此转发或部署的位置必须对应。

默认本地模型是 GPT-4.1 mini，模型名称以接口实际返回的目录为准。
可以选择更强的兼容模型，但必须支持 Chat Completions 与函数工具；
普通聊天或图像模型不一定适用。没有接口时，游戏不会用脚本冒充 AI。

## 游戏与存档

每款 RPG 都有自己的角色成长、物品或装备、任务条件和结局规则。
优先阅读当前目标和行动代价，角色的说法不一定等于世界的客观事实。
任务奖励不能重复领取；失败的模型请求不会扣除待提交的资源。

存档记录种子与经过规则校验的行动。导入时重新执行这些行动，而不是
相信任意 JSON 里的等级、物品或胜利标记。它不是联网反作弊系统；
单机代码与重放中的隐藏剧情信息可以被查看。

保存与导出不会包含 API 密钥。可选的浏览器密钥只放在当前页面内存，
刷新后消失；更推荐由自己的网关保管服务端密钥。模型会收到当前场景
需要的游戏内容与角色记忆，请勿在提交的自定义内容里放入敏感信息。

每个模型决策最多两次请求，每次最多 1,536 个完成 token，总等待上限
60 秒。第二次仅用于纠正不合法的计划。取消或重开会丢弃旧请求的结果，
但不能撤销服务商已经处理的 token。

## 扩展

各项目的中文 README 说明角色、剧情节点、场景、规则与扩展入口。
公共经济与成长函数在 `src/core/rpg/`，模型连接与工具校验在
`src/core/agents/`，存档重放在 `src/core/games/`。
新增角色或任务时，应同时更新数据、合法动作、界面说明和完整流程用例。
